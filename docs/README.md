# docs

Design notes, feature specs, and reference material for DW2 Mod Launcher that are too long-lived for a PR description or issue thread.

- [DLL-injection launch mechanism](DLL%20Injection.md) (CLI args, manifest schema)
- [CI and releases](CI%20Releases.md)
- [Mod author README](../Mod%20Author%20README.md): start here to make a mod (author name, settings, status widget, Mods menu, logging, channels, dependencies, and the build settings that keep "changed since last publish" honest)
- [Localization](Localization.md): launcher language packs, the in-game widget's language, translating the game and the docs
- [focus.md](focus.md): the running list of what the current branch has accomplished; becomes the PR description (reset by `scripts/new-branch.py`)

[archived/](archived/) holds finished plans kept for history (e.g. the [Linux support plan](archived/linux-support.md) and the [mod profiles design](archived/mod-profiles.md)).
