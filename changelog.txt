## v1.0.21
- Open Game Folder button in About, and on right-click of the info button
- Code mods can tell when a real game has started (game state), so they stop warning about menu data
- Rename Mod renames the folder, deletes the old DLL, renames the cover art and stored settings with it
- Mods with an unmet requirement or caution get a coloured row and a warning icon before launch

- Code hooks report from the right-click menu covers only that mod; hook details no longer fill the description

## v1.0.20
- hooksCoordinatedWith can name one version ("Mod@1.2.3")
- Rescans mods automatically when the game exits
- Code conflicts are remembered per mod and shown for mods not in the list

## v1.0.19
- Warns when two mods patch the same game code, in English, Japanese and Russian
- Details pane shows conflicts and cautions in separate collapsible bars naming the mods, with a Details button
- dw2modlauncher.json "hooksCoordinatedWith" marks mods whose overlapping game patches are already sorted out
- Live channels between code mods carry versions; a mismatch is reported in game
- Workshop mods without an author show their Steam creator's handle, and count as one author
- Author name defaults to the Steam account logged in on this machine
- Fixed a scrolling issue when doing a rescan of mods

## v1.0.18
- Mod list is always sorted in load order then name; headings no longer sort
- Added a filter string input and "local mods only" checkbox under the mod list
- A published local mod keeps its settings and enabled state when its folder is renamed
- Publish dialog footer tooltips open above their buttons instead of swallowing clicks
- Mark Up to Date says why when it cannot, and lists files that still differ afterwards
- In-game status line shows a code mod's mod.json version, not its assembly's
