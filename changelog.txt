## v1.0.17
- Publish dialog lists plain modified file names and shows last published
- Publish dialog gains a Save button; Steam description difference shown as a dot
- Replace-description checkbox became a setting: update Steam description when newer
- Description dot follows the publish record; red dot when edited on Steam, in Publish and Edit Properties
- Publish, push and pull of the description ask before overwriting a differing copy

## v1.0.16
- Local mods with a description file get mod.json's descriptionFile added automatically on scan
- Mod settings still at their old default follow the mod's new default
- Enabled mods can no longer be dragged past a load order rule; enabling snaps to the nearest valid place
- Edit Properties: erasing all change notes can now be saved, and Mark Up to Date writes pending edits first

## v1.0.15
- No longer asks for confirmation when launching a game (saves to current profile automatically)
- New "Mark Up to Date" right-click action records a modified mod's current files as what is on Steam
- Publish dialog lists Change notes above the modified files, no longer repeated inside it
- Publish dialog: wider, Mark Up to Date in the footer, one Publish button that reads Close when up to date
- Repo changelog.txt replaces docs/focus.md as the running record of changes
